# Civiclens-project
A Civiclens solution for community problems
Civilens – Improving Transparency and Coordination in Public Works Projects

1. Problem Statement :

Public works projects can face challenges such as a lack of transparency, poor coordination between stakeholders, delays in project completion, and difficulty for residents in tracking project progress. These challenges can make it difficult for citizens to access reliable information and report public work-related issues.

2. Proposed Solution :

Civilens is a CivicTech platform designed to improve transparency and coordination in public works projects. It aims to connect residents, service providers, and relevant authorities through a centralized platform where project information and updates can be shared.

3. Key Features :

- Public works project information and progress tracking.
- A platform for residents to report issues and share concerns.
- Better coordination between residents, service providers, and authorities.
- Project status updates to keep citizens informed.
- Improved access to public works information.

4. Technologies Used :

- Frontend: HTML -For the structure of the website
            CSS- For styling and layout
            Javascript - For source code hosting and project management
- Backend: pythonflash
- Database-MySQL
- Github - To host and manage the project source code 

5. Setup Instructions :
   
1. Download or clone this repository to your computer.
2. Open the project folder in Visual Studio Code.
3. Open the "index.html" file in your web browser.
4. Explore the Civic Lens features, including the Public Works Directory, Report Issue, Track Complaint, and Dashboard.

Requirements: A web browser and a code editor.



7. Project Goal

The goal of Civilens is to encourage transparent public works, improve coordination among stakeholders, and help residents stay informed about projects in their communities.
